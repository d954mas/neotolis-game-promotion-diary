# Phase 03.0.1 Plan 01: Test Scaffold + Foundation Interfaces Summary

**One-liner:** Ships the new `src/lib/sources/` tree with widened DataSourceAdapter contract, AdapterError 5-category taxonomy, empty SourceRegistry skeleton, CardProps interface, and Reddit-deferral host hint map; seeds 5 NEW test files per VALIDATION.md § Wave 0 Requirements with 20 active assertions GREEN and 19 test.todo / it.skip placeholders that later waves flip live.

## What Landed

### Foundation interfaces (7 files under `src/lib/sources/`)

1. **`adapter.ts`** (143 lines) — Widened `DataSourceAdapter` contract. SUPERSET of the legacy `src/lib/server/integrations/data-source-adapter.ts`. New surface beyond the legacy interface:
   - `AdapterContext { userId: string | null, origin: "cron" | "user" }` threads tenant + origin into every adapter call (D-06 Thick adapter scope, D-09 rate-limit budget split).
   - `parseUrl(url: string): ParsedUrl | null` — D-15 first-match-wins URL routing (Plan 06 wires the iteration in `services/ingest.ts`).
   - `observability: AdapterObservability` — per-adapter `auth { kind, requiresUserSetup, isOperatorConfigured }` + `quota.getDailyStats(date)` + `quota.getRecentAudit(limit)` for the multi-tab `/admin/quota` dashboard (D-08, Plan 08).
   - `registerQueues(boss)` / `scheduleCronTicks(boss)` / `backfillSource(source, ctx)` — adapter owns its queue topology, cron schedules, and per-source backfill enqueue (D-10 per-kind queues, Plan 05/07/10).
   - `canRefreshPoll?(eventKind)` — optional dispatch hint for the generic `POST /api/sources/:id/refresh-content` endpoint (Plan 10).
   - `MinimalBoss` interface — keeps adapter decoupled from pg-boss major-version type drift (Phase 1 Plan 03 pattern).

2. **`errors.ts`** (53 lines) — `AdapterError` class with the 5-category taxonomy from CONTEXT D-13. The `categoryToSnapshotStatus` mapper has no `default` branch, so adding a 6th category fails TypeScript compile (planned Phase 6 trigger when per-user credentials add `user-auth`). `Error.cause` is preserved (Node 22).

3. **`registry.ts`** (21 lines) — Empty `Map<SourceKind, DataSourceAdapter>` skeleton. `getAdapter(kind)` throws `Error('No adapter registered for kind=…')` for every kind pre-Plan-03. `allAdapters: DataSourceAdapter[]` is `[]` until Plan 03 wires `youtubeAdapter`.

4. **`registry-ui.ts`** (19 lines) — Empty `Map<SourceKind, AdapterUiServer>` skeleton. Plan 09 wires per-kind `toCardProps` mappers + Svelte components.

5. **`card-props.ts`** (11 lines) — Universal `CardProps { thumbnail, title, subtitle, badge, metrics[], href }` interface. The `<EventCard>` shell (Plan 09) consumes this shape; per-source mappers fill the slots.

6. **`future-kinds.ts`** (28 lines) — `FUTURE_KIND_HOSTS` Map ({ "reddit.com" → "reddit_post", "www.reddit.com" → "reddit_post", "old.reddit.com" → "reddit_post", "redd.it" → "reddit_post" }) + `detectFutureKind(input)` helper. Used by `services/ingest.ts` AFTER `parseAnyUrl` returns `unsupported` to surface the friendly inline-info `AppError(422, 'reddit_pending_phase3')` for Reddit URLs. Phase 03.1 removes the `reddit_post` entry once the real Reddit adapter ships.

7. **`index.ts`** (6 lines) — Barrel re-export.
