## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking issue] Plan 01's widened DataSourceAdapter contract typed v0.1 methods (pollContent / pollStats / pollStatsByVideoId) with `ctx: AdapterContext` instead of the legacy `picked: PickedKey` + `quotaUser: string`. Plan 01's PR notes claimed "the new interface is a STRICT SUPERSET of the legacy one" — that was incorrect.**

- **Found during:** Task 1, after writing the widened-contract stubs and running `pnpm exec tsc --noEmit` — TypeScript surfaced the signature mismatch (`pollStats(events, source, picked: PickedKey)` from the legacy implementation does NOT satisfy `pollStats(events, source, ctx: AdapterContext)` in the widened contract).
- **Issue:** The plan's must-have explicitly states "the existing v0.1 implementations (pollContent / pollStats / pollStatsByVideoId) must NOT be modified beyond fixing the imports — preserve their current behavior verbatim." But the widened contract from Plan 01 dropped PickedKey from these methods. Reconciling the contradiction required deciding whether to:
  - (a) refactor callers (poll-active / poll-cold / poll-user / rehab-unavailable) to NOT thread PickedKey, having the adapter pick internally — but callers ALSO need `picked.apiKeyId` for `writeSnapshot()` calls, so this requires returning `apiKeyId` on every `StatsSnapshot` (schema-level change, not Plan 03 scope), or
  - (b) keep PickedKey + quotaUser in the widened contract for v0.1 methods, deferring the Thick-adapter D-06 refactor to Plan 04/08.
- **Fix:** Option (b). Updated `src/lib/sources/adapter.ts` to:
  - Re-introduce the `PickedKey` interface (with the load-bearing jsdoc explaining round-robin index integrity).
  - Type `pollStats(events, source, picked: PickedKey)` and `pollStatsByVideoId(videoIds, quotaUser, picked: PickedKey)` to match the legacy contract verbatim.
  - Type `pollContent(source, since)` (legacy 2-arg form) — Plan 01's widened version had a 3rd `ctx` arg that was unused by the implementation anyway.
  - Keep `AdapterContext` defined (Plan 06 parseUrl-iterators consume it; Plan 10 backfillSource consumes it).
  - Updated the file header to document the deviation rationale.
