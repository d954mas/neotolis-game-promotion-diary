Rather than delete it (the contract type still requires the method), we change the message to match the registerQueues stub: 'fallback hit — import youtubeAdapter from index.js (the barrel composes the real impl)'. Consumers that bypass the barrel surface the bug loudly."

**1. [Rule 2 — Missing critical functionality] DO $$ schema-existence guard added to migration 0021**

- **Found during:** Task 1 — drafting the migration file from the plan's verbatim SQL block.
- **Issue:** The plan's verbatim SQL was three bare `DELETE FROM pgboss.schedule|queue|job` statements. - **Fix:** Wrapped the three DELETEs in `DO $$ BEGIN IF EXISTS (...) THEN ...
