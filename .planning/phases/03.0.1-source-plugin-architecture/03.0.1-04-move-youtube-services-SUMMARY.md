## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking issue] Tenant-scope ESLint rule unregistered for the new file location.**

- **Found during:** Task 1, after the four `git mv` operations + import retargeting, when running `pnpm exec eslint .` to verify the lint gate.
- **Issue:** The relocated `src/lib/sources/youtube/server/quota.ts` carries an `eslint-disable-next-line tenant-scope/no-unfiltered-tenant-query` directive on the `audit_log` defense-in-depth lookup inside `markThrottleTransition` (the cross-restart guard for the per-day `(date_pacific, state)` audit-emission idempotency). The original file lived under `src/lib/server/services/`, which the rule's `files` glob covered. The new location (`src/lib/sources/youtube/server/`) is NOT in the original glob — so when ESLint hit the disable directive, it errored: `Definition for rule 'tenant-scope/no-unfiltered-tenant-query' was not found`. This blocks the lint gate.
- **Fix:** Extended `eslint.config.js` `files` array to include `src/lib/sources/**/server/**/*.ts`. Per CONTEXT D-14, the per-source server folder executes the same tenant-scope discipline as `services/` — extending the glob preserves the lint-time guard intact through the move and aligns the rule's coverage with where tenant-scoped queries actually run. The rule's `ALLOWLIST_TABLES` already covers `youtubeServiceQuotaUsage` / `youtubeVideos` / `youtubeVideoSnapshots` / `youtubeChannels` (verified) so no other code under the new glob fires the rule unintentionally.
- **Why not drop the disable directive instead:** That would lose the rationale citation (the disable carries an inline `--` justification per AGENTS.md Pitfall 7). The disable exists because the audit_log lookup is intentionally cross-tenant for the operator-emitted `quota.service_throttled` row's idempotency. Removing it would silence the rationale and make the next reviewer wonder why the cross-tenant query is there. Extending the glob keeps the rule active AND keeps the disable + justification colocated.
- **Files modified:** `eslint.config.js` (4 added lines + 5 lines of explanatory comment).
- **Commit:** `e80f9fd`.
