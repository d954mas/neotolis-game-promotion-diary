## Decisions Made

See `key-decisions` in frontmatter. Highlights:

- **Mirror tier-resolver inline + paired test** — the cheapest way to honor Pitfall 7 without refactoring `tier-resolver.ts` out of `$lib/server/`. The mirror is 7 lines of code; the paired test is 95 lines of guard. Drift in either side fails the test.
- **Browser-test path deviation** — vitest browser mode's vite import-analysis can't resolve `$app/navigation` even with `vi.mock`; the mock runs after the static import has already failed. Integration project (Node env) handles vi.mock correctly. Same path Plan 03.0-12's `tests/unit/account-deleted-banner.test.ts` took for the same reason. The 14 SSR assertions in `tests/integration/polling-badge-render.test.ts` cover the same surface the plan asked for in `tests/browser/polling-badge.test.ts`.
- **Refresh-now visible on Frozen even when lastPolledAt would suggest otherwise** — D-10's "OR Frozen" branch is the rescue path for old events. Plan 04's `requestRefreshPoll` service accepts Frozen-tier requests; Plan 11's UI exposes the affordance.
- **Server is the cooldown authority** — RefreshNowButton reads `event.metadata.last_user_refresh_at` (the same field Plan 04's service writes) instead of maintaining its own clock. setInterval(30s) re-evaluates from the latest metadata; on 200/202, `invalidateAll()` triggers the parent loader and the next render reads the fresh server-side timestamp.
