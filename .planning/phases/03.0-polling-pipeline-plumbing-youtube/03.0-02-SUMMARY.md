- **DV-1 per-platform split landed in two commits:** PROJECT.md component shipped in the pre-existing `docs(state)` commit (`dc8c6bc`); REQUIREMENTS.md component shipped here in `9f765f6`. The split keeps each commit atomic — `dc8c6bc` is the PROJECT.md / ROADMAP.md / STATE.md artifact-set the discuss/research/UI-SPEC steps had pre-staged, and `9f765f6` is the REQUIREMENTS.md inline-annotation work that this plan owns.

Plan 02.2-01 precedent. - **PollingBadge.svelte switches to `polling_badge_manual` (not a new transitional key):** the never-polled-yet branch was the lone code consumer of the retired `polling_badge_phase3_placeholder`. UI-SPEC explicitly retains `polling_badge_manual` ('Manual entry — no polling') for the never-polled-yet edge case. Plan 03.0-11 lands the live tier-driven rewrite that replaces this component wholesale; until then, the badge keeps its Phase 2.1 contract (one element, role="status") but with non-deprecated copy.
