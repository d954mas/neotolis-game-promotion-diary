## Accomplishments

- **`tier-resolver.ts` — single source of truth (Pitfall 7).** Pure function `resolveTier(occurredAt, lastPollStatus, now)` returning `'active' | 'cold' | 'frozen' | 'unavailable'` deterministically per CONTEXT D-05 (24h / 28d boundaries) + D-12 (`not_found` / `private` / `auth_error` overrides). Exported boundary constants `TIER_BOUNDARY_ACTIVE_MS` / `TIER_BOUNDARY_COLD_MS` and override list `UNAVAILABLE_POLL_STATUSES` so consumers reference one symbol, never re-derive the literal `86_400_000`.
- **`youtube-quota-tracker.ts` — operator-side YouTube Data API v3 quota accounting (D-13 + Pattern 4).** Public surface:
  - `pickKeyForJob()` — round-robin across `env.SERVICE_YOUTUBE_API_KEYS`; returns `null` on empty env (smoke + self-host parity).
  - `incrementUsage({apiKeyId, units, tx?})` — UPSERT `(date_pacific, api_key_id) += units` with composite-PK race safety; accepts caller-supplied tx for atomic commit-with-snapshot in Plan 03.0-04.
  - `getThrottleState(now?)` — returns the WORST state across all keys for today: `'ninetyfive'` (>= 9500), `'eighty'` (>= 8000), else `'ok'`. Scheduler short-circuits BEFORE enqueue.
  - `markThrottleTransition({state, apiKeyId, estimatedUnits})` — writes `quota.service_throttled` audit row ONCE per `(date_pacific, state)` with two-layer idempotency (module-level Set + audit_log lookup).
  - `todayPacific(now?)` — `'YYYY-MM-DD'` in `America/Los_Angeles` via `Intl.DateTimeFormat` with `sv-SE` locale (DST-aware; PDT and PST handled by runtime).
  - `hashApiKeyId(apiKey)` — sha-256 first 8 hex chars; stable identifier stored in `youtube_service_quota_usage`.
  - `resetThrottleState()` — exported hook for the `youtube.quota_reset` cron handler (Plan 03.0-09): clears the Map, resets `roundRobinIdx`, drops the cached operator id.
  - Threshold constants `THROTTLE_EIGHTY_THRESHOLD = 8000` / `THROTTLE_NINETYFIVE_THRESHOLD = 9500` exported alongside the functions that consume them so /admin/quota copy and integration tests reference one symbol.
- **47 live tests covering all behaviours:** 17 tier-resolver boundary + override + constant cases; 19 quota-tracker pure-function cases (round-robin cycling, DST-aware date table with 7 UTC→PT mappings spanning May/January, threshold-constants invariants, reset hook); 11 DB-touching integration cases (UPSERT accumulation, per-key separation, getThrottleState 5-row threshold table, markThrottleTransition 3-row idempotency table).

## Decisions Made

- **Test file split (unit vs integration).** The Plan 02 placeholder lived in `tests/unit/youtube-quota-tracker.test.ts` only, but the DB-touching cases (UPSERT accumulation, getThrottleState against live rows, markThrottleTransition idempotency) require real Postgres. Following the `tests/integration/quota.test.ts` precedent, pure-function tests stayed in unit (with `vi.resetModules` + dynamic import for env-dependent SERVICE_YOUTUBE_API_KEYS state) and DB-touching tests moved to `tests/integration/youtube-quota-tracker.test.ts`. The plan's note "use real Postgres test DB (integration-style; the file lives in tests/unit/ but uses db setup helpers ...)" was the explicit license for the split.
- **Operator user_id resolution as private helper, not shared module.** `resolveOperatorUserId()` lives inside `youtube-quota-tracker.ts` because it's the only current caller. If Plan 03.0-13 (admin quota page) or another future module needs the same resolution, we revisit factoring at three concrete callers (Practices: "no premature abstraction").
- **Threshold constants exported.** `THROTTLE_EIGHTY_THRESHOLD = 8000` and `THROTTLE_NINETYFIVE_THRESHOLD = 9500` are named exports so /admin/quota Paraglide messages and integration tests reference one symbol. Acceptance-criteria grep `grep "9500"` and `grep "8000"` both succeed against the source file.
- **ESLint inline disable on audit_log lookup, with multi-line rationale.** `markThrottleTransition`'s defense-in-depth audit_log query is intentionally not user-id scoped — the (date_pacific, state) composite is the natural idempotency key, and adding a userId filter would defeat the cross-restart guard. Inline `eslint-disable-next-line tenant-scope/no-unfiltered-tenant-query` with a 6-line comment block explaining the operator-side semantic.
