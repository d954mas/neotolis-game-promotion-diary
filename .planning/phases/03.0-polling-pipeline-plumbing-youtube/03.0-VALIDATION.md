## Sampling Rate

- **After every task commit:** Run `pnpm test:unit` (the unit suite covering files touched by the task)
- **After every plan wave:** Run `pnpm test` (unit + integration; Postgres container required for integration)
- **Before `/gsd:verify-work`:** Full suite (`pnpm lint && pnpm typecheck && pnpm test && pnpm test:smoke`) must be green
- **Max feedback latency:** ~25s for unit, ~120s for full integration, ~5min for smoke
