## API-Surface Sanity Check on the Redaction Engine Swap

pino 10.1.0 swapped `fast-redact` for `@pinojs/redact`. Per pino's `docs/redaction.md`, the API surface is preserved:

- **Dotted paths** (e.g. `req.headers.authorization`) — preserved.
- **Bracket paths** (e.g. `a["b-c"].d`) — preserved (we don't use this shape).
- **`*` full-segment wildcards** (e.g. `*.password`, `req.headers.*`) — preserved. Our `REDACT_PATHS` is overwhelmingly `*.foo` shapes; the runtime tripwire confirms the wildcard semantics carry over.
- **`censor` option** — preserved (`"[REDACTED]"` continues to be emitted).
- **New: `remove` option** — additive opt-in (omits keys entirely); we do NOT use it. No behavior change.
- **Safety improvement:** `@pinojs/redact` does NOT mutate the input object during redaction (a fast-redact footgun). We don't rely on the old mutate-or-not behavior — strictly safer.
