## Sampling Rate

- **After every task commit:** Run the relevant quick command for the bump class (per-commit map below). Push to branch → CI runs full matrix.
- **After every atomic unit (when bump + fix-up span 2 commits):** Both commits MUST be green individually per D-02. Push both, verify CI on each.
- **Per phase gate (final PR):** Full CI matrix green on the latest commit; smoke job is the load-bearing trust signal per D-03.
- **Max feedback latency:** Local ~120s; CI green-signal ~5–8 min per push.

Per D-02 every commit on the branch MUST be green on ALL three CI jobs. Sampling rate is therefore: **100% — every commit runs the full CI matrix on push.**
