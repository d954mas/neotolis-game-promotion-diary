<objective>
Land the third atomic commit of Phase 03.0.2: bump `dotenv` from ^16.4.5 to ^17.4.2 AND silence its new boot-time advertising line.

dotenv 17 flipped the `quiet` option default from `true` to `false`, so every `config()` call now emits an unstructured stdout line `[dotenv@17.x] injecting env (N) from .env – [tip] encrypt with dotenvx: https://dotenvx.com`. That line would corrupt Pino's JSON log stream in production containers (the promtail/loki ingestion pipeline expects pure JSON). The bump MUST be paired in the SAME atomic unit with a 2-line edit in `src/lib/server/config/env.ts` to pass `{ quiet: true }` to both `loadDotenv()` call sites.

This is the smallest real code change in the phase — but it touches the SOLE legitimate `process.env` reader (AGENTS.md "One source of truth for env"), so the privacy/architecture invariant `eslint: no-restricted-properties` MUST stay enforced and unchanged.

Purpose: Bring dotenv to latest stable; preserve structured-JSON log discipline in production; preserve the env-reader carve-out invariant.
Output: One commit `chore(deps): bump dotenv from ^16.4.5 to ^17.4.2` (with the env.ts edit included via amend, OR a follow-up `fix(03.0.2): silence dotenv 17 advertising via { quiet: true }` commit immediately after); CI green on all three jobs.
</objective>
